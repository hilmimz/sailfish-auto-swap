# sailfish-auto-swap

A program to automate a swap transaction on SailFish VeDEX

## Requirements
- NPM
- Node.Js

## How to use?

1. Clone this repository

2. Install dependencies
   ```bash
   npm install
   ```

3. Write your private key on config.json
   ```json
   {
     "privateKey": "your_private_key_here",
   }
   ```

4. Run the program
   ```bash
   node app.js
   ```
